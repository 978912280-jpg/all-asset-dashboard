计算口径：市值 = 持有份额 × 最新价格 × 汇率（USD/USDT → CNY）。未实现盈亏 = 市值 − 持仓成本（份额 × 成本价 × 汇率），收益率 = 未实现盈亏 / 持仓成本。传统标的价格取自「全球资产仪表台」已抓取的行情，缺失时回退腾讯实时 / 东方财富基金 / Yahoo；加密资产直连 Bitget 私有接口（现货 + 理财），成本按成交回放的平均成本法自动维护，加密盈亏百分比的分母只算币类成本（剔除稳定币面值）。

当日浮动收益：按「上一份快照里的份额 × 当日价差 × 汇率」计算。这样即使某天没及时更新份额、事后才补录，历史日历上的数字也不会被改写；补录当天新增的份额不计入当日盈亏（视为收盘价买入）。若没有更早的快照可用，才退化为「今日份额 × 当日涨跌幅」。

资金流水口径：加密部分直读 Bitget 只读接口，按业务类型分四类——成交归「交易记录」，派息/锁仓收益/活动奖励归「理财记录」（按日汇总，不展示小时明细），链上充提归「出入金」，账户间划转与划入美股账户归「内部划转」。净入金 = 2026-11-13 基准 17296 USDT（转入 Bitget 总额，其中约 2231 USDT 已划入美股账户）+ 基准日之后的链上充值 − 基准日之后的链上提现；加密账户口径为 15065 USDT（剔除划往美股的部分），加密收益率以它作分母。内部划转本身不计入净入金。「已实现盈亏」独立口径，只统计已卖出部分，不与「总盈亏」相加。

份额来源：仅 data/holdings.json 中的 shares 为人工维护，价格、市值、占比、日变动全部由后台脚本自动计算。修改份额后需重新运行 python3 scripts/build.py 或等待 GitHub Actions 每日构建。

本页面仅用于个人资产记录与研究，不构成任何投资建议。
