传统股票 & 基金 + 加密货币 · 份额 × 价格 = 市值

v— 数据更新时间：— 份额维护后台

计算口径：市值 = 持有份额 × 最新价格 × 汇率（USD/USDT → CNY）。浮动盈亏 = 市值 − 持仓成本（份额 × 成本价 × 汇率），收益率 = 浮动盈亏 / 持仓成本。传统标的价格优先取「全球资产仪表台」已抓取的行情，缺失时回退腾讯实时 / 东方财富基金 / Yahoo；加密货币直接读取「加密货币资产仪表台」的最新快照（现货 + 理财合并），其盈亏按该仪表台的净入金口径（真实盈亏）折算。

份额来源：仅 data/holdings.json 中的 shares 为人工维护，价格、市值、占比、日变动全部由后台脚本自动计算。修改份额后需重新运行 python3 scripts/build.py 或等待 GitHub Actions 每日构建。

本页面仅用于个人资产记录与研究，不构成任何投资建议。
